## 📖 简介

**Dollop Cast** 允许您将浏览器中的在线视频流（HLS/MP4）、甚至是受防盗链保护的平台视频（如优酷、B站、腾讯视频、爱奇艺等），一键完美投射到局域网内的各类 DLNA/UPnP 设备（智能电视、电视盒子、投影仪等）上大屏播放。它内置了强大的流媒体代理机制，解决了传统投屏无法播放加密流的痛点。

---

## ✨ 核心特性

- 🕵️ **智能嗅探与直投**：浏览器扩展自动捕获网页中的视频直链（`.m3u8`, `.mp4` 等），点击即投，速度极快。
- 🛡️ **突破防盗链限制 (黑科技)**：内置本地流式代理（Stream Proxy），自动改写播放列表并注入 `Referer` / `User-Agent`，完美支持投屏**优酷、B站、腾讯、爱奇艺、百度网盘**等平台的视频。
- 🚀 **极致流畅播放体验**：
  - **连接复用池**：大幅提升切片下载速度，消除网络握手延迟。
  - **后台分批预加载**：智能缓冲视频切片，彻底告别投屏卡顿。
  - **大文件 Range 透传**：支持 MP4/FLV 等单体大文件流式投屏，支持电视端随意拖动进度条。
- 📂 **本地文件直投**：支持通过托盘菜单直接选择电脑上的本地视频文件（`mp4`, `mkv`, `avi` 等），一键极速投送电视。
- 🖥️ **系统托盘集成**：轻量化运行于系统托盘，实时自动扫描局域网 DLNA 设备，一键动态切换投屏目标。
- 🐛 **开发者友好**：自带“本地调试模式”，可在 PC 浏览器内快速验证流媒体代理链接是否生效，免去频繁测试电视的烦恼。

## 🛠️ 安装指南

### 1. 后端服务部署

确保您的系统已安装 [Python 3.8+](https://www.python.org/)。

```bash
# 1. 进入项目根目录
cd Dollop-Cast

# 2. 安装所需依赖库
pip install -r requirements.txt
```
> *(注：核心依赖包括 `flask`, `flask-cors`, `yt-dlp`, `requests`, `pystray`, `Pillow` 等)*

### 2. 浏览器插件安装 (Chromium 内核)

支持 Google Chrome, Microsoft Edge, Brave 等主流浏览器。

1. 打开浏览器的扩展程序管理页面（例：`chrome://extensions` 或 `edge://extensions`）。
2. 在右上角开启 **“开发者模式”**。
3. 点击 **“加载已解压的扩展程序”** (Load unpacked)。
4. 选择并导入本项目目录下的 `browser_extension` 文件夹。

## 🚀 快速上手

### 步骤一：启动后端服务

在项目目录下双击运行或通过命令行执行：

```bash
python tray_app.py
```

- 启动成功后，屏幕右下角系统托盘将出现 **蓝色电视图标 (Dollop Cast)**。
- 🚨 **右键点击托盘图标**，在弹出的菜单中选择您的电视设备（打钩 ✅ 即为选中状态）。

### 步骤二：开始投屏

只需两步，大屏享受：

1. **🌐 网页视频提取投屏 (配合插件)**
   - 在浏览器中正常打开并播放想要投屏的视频（如 Bilibili, 在线影视大全）。
   - 点击浏览器右上角的 **Dollop Cast 插件图标**。
   - 如果插件列表显示数字，说明成功嗅探到了视频源，点击绿色 **[投屏]** 按钮即可。
   - 若列表为空，可点击底部的 **“解析并投屏当前网页”**，后端服务将尝试调用底层解析器捕获视频。

2. **� 本地视频文件投屏 (无需插件)**
   - 右键电脑任务栏托盘的 Dollop Cast 图标。
   - 选择菜单中的 **[投放本地文件...]**。
   - 在弹出的操作系统的文件选择框中选定您的本地视频，即刻推送到电视播放。

## ⚙️ 进阶配置与调试

右键托盘菜单，您可以快捷控制以下核心开关：

- 🛡️ **启用防盗链代理** (默认开启)：针对各大受限视频流网站的必备开关。关闭后将采用原始直连投屏（仅适用于无防盗链校验的普通 m3u8/mp4 链接）。
- 🐛 **启用本地调试 (浏览器播放)**：开启后，所有的投屏指令将被拦截，不再发往电视，而是**自动在您的默认浏览器中打开并尝试播放流媒体代理链接**。非常适合排查网络异常或防盗链策略。
- 🔄 **手动重扫**：如果您的电视刚才开机或网络发生波动，可以在菜单中点击手动重新扫描局域网内的 DLNA 设备。

## 📁 核心架构结构

```text
Dollop-Cast/
├── tray_app.py           # 📌 [核心入口] Flask 后端与系统托盘 UI 管理，控制调度中心
├── stream_proxy.py       # 🛡️ 智能媒体代理层 (防盗链注入, 预加载缓存, 大文件 Range 支持)
├── extract_video.py      # 🔍 基于 yt-dlp 的视频直链通用解析引擎
├── dlna_play_url.py      # 📡 SSUP/DLNA 协议底层发包与局域网投屏控制
├── bili_parser.py        # 📺 哔哩哔哩专属高帧率/直连视频极速解析器
├── browser_extension/    # 🧩 浏览器端媒体资源嗅探插件源码
├── cache/                # 🗂️ 运行时的 m3u8 清单转化与 TS 媒体临时分片缓存
└── requirements.txt      # 📦 必要的 Python 第三方库依赖列表
```
